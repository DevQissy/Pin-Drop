# PinDrop

**A Pinterest media downloader for Android.**

PinDrop is an Android application designed to download Pinterest media and manage saved files in one place.

## Features

- **Pinterest Downloads** — Download supported media using a Pinterest link.
- **Download Management** — View download history and manage active or completed downloads.
- **Saved Files** — Browse downloaded images and videos.
- **Media Sharing** — Share saved media with other applications.
- **File Management** — Delete unwanted files from your collection.
- **Background Downloads** — Manage downloads through an Android foreground service.
- **Modern Interface** — Built with Kotlin and Jetpack Compose.

## Installation

### Download the APK

1. Open the project's [GitHub Releases](https://github.com/DevQissy/PinDrop/releases) page.
2. Download the latest APK release.
3. Open the downloaded APK on your Android device.
4. If prompted, allow your browser or file manager to install apps from that source.
5. Follow the Android installation instructions.

Only install APKs from a source you trust. If Android displays a security warning, verify the file's origin and authenticity before proceeding.

**Note:** PinDrop may not be available through Google Play. Installing an APK outside an official app store carries additional security risks.

## Permissions

Depending on your Android version and the features you use, PinDrop may request permissions related to:

- Notifications for download progress.
- Background operation and battery optimization.
- Access to media files for browsing, sharing, or deleting saved content.

Grant only the permissions needed for the features you intend to use.

## How to Use

1. Copy a link to the Pinterest content you are authorized to download.
2. Open PinDrop and enter the link.
3. Start the download and wait for processing to finish.
4. Find your saved media in the Files section.
5. Manage previous downloads in the Downloads section.

Availability and download results depend on the content, its accessibility, and the application's supported formats.
